# 2-Knowledge/

## Purpose

This is where your knowledge lives. Everything here should be findable, queryable, and useful to your future self.

## Structure

```
2-Knowledge/
  HowTo/        # Step-by-step guides and processes
  Decisions/     # Decision records with context and rationale
  References/    # Manuals, specs, architecture docs, reference material
```

## Conventions

- Every file gets the metadata standard (see `_config/standard.md`)
- File names should be descriptive and searchable
- Use the templates in `_meta/templates/` for consistency

> **Note:** During the training period, your AI may suggest additional subdirectories based on your usage patterns. This structure will adapt to your needs.
